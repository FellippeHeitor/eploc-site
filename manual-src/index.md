# Manual do eploc

O **eploc** é uma extensão gratuita para Google Chrome e Microsoft Edge que acrescenta painéis,
atalhos e automações ao **eproc**, ao **SEI**, ao **RUPE** e a páginas do **TJMG**, sem mudar o jeito
como esses sistemas funcionam. Cada melhoria é uma funcionalidade separada, que você liga ou desliga
quando quiser.

Este manual explica, para cada funcionalidade, o que ela faz, onde aparece, como usar, quais opções
tem e o que ela não faz.

## Por onde começar

- **Primeira vez?** Siga o [Início rápido](./inicio-rapido): instalação, permissões, conexão com o
  Google Drive e primeira configuração.
- **Procurando um recurso?** Use a busca (no topo da página) ou a lista de
  [Funcionalidades](./funcionalidades/).
- **Dúvidas sobre dados?** Veja [Privacidade e dados](./privacidade).
- **Precisa enviar o manual a um tribunal ou à equipe de TI?** Baixe a
  [versão em PDF](https://eploc.com.br/manual/eploc-manual.pdf), com todo o conteúdo deste site.

## Como ler as páginas de funcionalidade

Toda página de funcionalidade segue o mesmo molde:

| Parte | O que traz |
|---|---|
| Selos no topo | Sistema (eproc, RUPE, SEI ou TJMG), plano (**Free** ou **Pro**), versão em que surgiu e se vem ligada ou desligada |
| O que faz | Resumo em 2 ou 3 frases |
| Onde aparece | Sistema e tela |
| Passo a passo | Como usar |
| Configurações e opções | As opções do card da funcionalidade, com o valor padrão |
| Limitações e problemas conhecidos | O que ela não faz ou onde pode falhar |

O nome de cada página é o mesmo que aparece nas configurações do eploc, para você encontrar o card
correspondente com a busca das configurações.

::: tip Exemplos fictícios
Todos os números de processo, nomes, CPFs e demais dados usados nos exemplos deste manual são
fictícios.
:::

::: warning Confira sempre
O eploc é um auxílio. A conferência de todos os atos praticados nos sistemas oficiais continua sendo
de quem os pratica (veja os [termos de uso](https://eploc.com.br/termos)).
:::
