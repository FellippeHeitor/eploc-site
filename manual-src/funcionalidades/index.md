# Funcionalidades

Cada recurso do eploc tem uma página própria, sempre com as mesmas partes: o que faz, onde aparece,
passo a passo, configurações, limitações, o selo Free/Pro e a versão em que surgiu. Use o menu
lateral ou a busca para encontrar um recurso pelo nome.
