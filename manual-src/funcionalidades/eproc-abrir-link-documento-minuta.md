# Abrir documentos citados no editor de minutas

## O que faz

No editor de minutas, os links para documentos do processo (como "evento 1, INIC1") não abrem com
um clique: o duplo clique mostra uma janelinha "Link para documento de processo", e só o botão
"Abrir" dela abre o documento. Com este recurso, basta passar o mouse sobre o link e clicar no botão de abrir
que aparece logo abaixo dele.

## Onde aparece

**eproc**, no editor de minutas (ao criar ou editar uma minuta).

## Passo a passo

1. Abra a minuta para edição.
2. Passe o mouse sobre um link para documento do processo.
3. Clique no botão de abrir (seta saindo de um quadrado), logo abaixo do link. O documento abre.

Para editar o texto ou a página do link, dê um duplo clique no link, como antes: a janelinha do eproc continua
disponível.

## Configurações e opções

Não há opções além de ligar e desligar.

## Observações

O botão usa a mesma função do "Abrir" do eproc, então o documento abre do mesmo jeito que pela
janelinha, mas sem abri-la e sem alterar o link na minuta.
